# 🌿 Baires Green Market

Marketplace profesional de jardinería para Buenos Aires.  
Conecta paisajistas, viveros y proveedores con sistema de consolidación de pedidos por camión.

## Funcionalidades

- 📦 **Catálogo** — 36+ productos en 8 categorías (plantas, tierra, grama, riego, herramientas, iluminación, piedras, macetas)
- 🚛 **Consolidación de camiones** — Los pedidos se agrupan por zona, se comparte el flete y se ahorra hasta 40%
- 👥 **Compra grupal** — Precios mayoristas al comprar entre varios paisajistas
- 👷 **Red de profesionales** — Referí clientes a otros paisajistas y ganá comisión
- 📊 **Dashboard** — Panel de comisiones, métricas y últimas transacciones
- 📍 **Zonas de entrega** — GBA Norte, Sur, Oeste, CABA y Nordelta/Countries

## Instalación local

```bash
npm install
npm start
```

Se abre en [http://localhost:3000](http://localhost:3000)

## Deploy en Vercel

1. Subí el repo a GitHub
2. Andá a [vercel.com](https://vercel.com) y conectá tu cuenta de GitHub
3. Importá el repositorio `baires-green-market`
4. Vercel detecta automáticamente que es un proyecto React
5. Click en **Deploy** — ¡listo!

Tu app va a estar en: `https://baires-green-market.vercel.app`

## Tecnologías

- React 18
- CSS-in-JS (inline styles)
- Google Fonts (DM Sans + Fraunces)
